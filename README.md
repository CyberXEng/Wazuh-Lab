Wazuh PoC — File Integrity & Blocking Malicious Actor

This repository contains a Proof‑of‑Concept setup and instructions to:

Install Wazuh manager (single‑node)

Configure File Integrity Monitoring (FIM) on Windows and Kali agents (PoC)

Detect & block a malicious actor (Kali attacker targeting a CentOS web server) using Wazuh active response and IP reputation
